# AI Tooling Digest - 2026-11-19

**Theme:** Agent interoperability and the builder-facing API/CLI layer.

## 1. openai-node 7.60.0 adds Live MCP server configuration to the API surface

The TypeScript SDK now exposes typed configuration for Live MCP servers, so builders can wire MCP servers into OpenAI-side sessions without hand-rolled request shapes. The release also adds standalone CSAM moderation types and hides Managed Agents session budget controls and events from the public surface, which affects anyone who relied on those types.

**Source:** [GitHub - openai-node v7.60.0 release](https://github.com/openai/openai-node/releases/tag/v7.60.0)

## 2. MCP Inspector 2.16.0 adds load-test headers and an opt-in cookie jar

The official MCP debugging tool now shows the target rate in a stepped `--load` run header and offers an opt-in per-server HTTP cookie jar for sticky sessions. Server authors can now load-test and debug MCP servers that sit behind session-affine load balancers, and a showcase config exercises `--load-subscribe` resource updates.

**Source:** [GitHub - modelcontextprotocol/inspector 2.16.0 release](https://github.com/modelcontextprotocol/inspector/releases/tag/2.16.0)

## 3. Gemini CLI 0.69.0 adds a /stats heatmap for daily token usage

The stable release adds a `/stats heatmap` subcommand, giving users a per-day view of token consumption inside the CLI. It also fixes ACP tool call updates so ANSI output is serialized to text and preserves literal `$` characters during template placeholder replacement, which matters to editors and scripts that drive the CLI.

**Source:** [GitHub - gemini-cli v0.69.0 release](https://github.com/google-gemini/gemini-cli/releases/tag/v0.69.0)

## 4. LangGraph 1.2.23 gives Send-dispatched tool calls the same state as an edge

Tool calls dispatched through `Send` now receive the same state as calls routed by an edge, removing a state mismatch that could make parallel tool-calling graphs behave differently from sequential ones. The fix ships in langgraph 1.2.23 and prebuilt 1.1.3, so agents built on the prebuilt tool node pick it up on upgrade.

**Source:** [GitHub - langgraph 1.2.23 release](https://github.com/langchain-ai/langgraph/releases/tag/1.2.23)

## 5. TensorRT-LLM v1.4.0rc4 adds new model targets and lists known issues

This release candidate adds PyTorch backend support for Apertus models and NVFP4 targets for GLM-5.2, GLM-5.3-Flash, MiniMax-M3 and Qwen3.8-Flash-Next, plus native Qwen3 reranking. It is a prerelease, and the notes list known issues such as incorrect DeepSeek-R1 FP4 disaggregated output on B300 under CUDA graphs, so teams serving on NVIDIA hardware should test before adopting.

**Source:** [GitHub - TensorRT-LLM v1.4.0rc4 release](https://github.com/NVIDIA/TensorRT-LLM/releases/tag/v1.4.0rc4)
