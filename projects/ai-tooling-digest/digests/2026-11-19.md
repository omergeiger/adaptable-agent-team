# AI Tooling Digest - 2026-11-19

**Theme:** AI tooling - agent infrastructure and coding-assistant runtimes

## 1. Gemini 4 Neon becomes generally available in GitHub Copilot

Builders on Copilot can now pick Gemini 4 Neon across supported IDEs, Copilot CLI, the coding agent, and github.com, billed at provider list price under usage-based billing. It is available to Pro+, Max, Business, and Enterprise users on a gradual rollout, with Business and Enterprise admins controlling access through the model policy.

**Source:** [GitHub Changelog - Gemini 4 Neon in GitHub Copilot](https://github.blog/changelog/2026-11-18-gemini-4-neon-in-github-copilot)

## 2. GitHub Copilot adds eight GitHub-verified MCP connectors in public preview

Copilot can now reach Box, Buildkite, Calendly, ClickUp, Mixpanel, Supabase, Webflow, and Wix through verified MCP servers, so one connection works across the Copilot app, CLI, VS Code, and github.com. They join more than 25 existing connectors, and Business and Enterprise teams need the "Editor preview features" policy enabled and possibly an MCP allowlist update.

**Source:** [GitHub Changelog - Connect Supabase, Box, Calendly, and more to Copilot](https://github.blog/changelog/2026-11-18-connect-supabase-box-calendly-and-more-to-copilot)

## 3. Claude Code 2.1.328 brings auto mode to third-party cloud providers

Auto mode now works for Opus 4.6 and Sonnet 4.6 on Bedrock, Google Agent Platform, Foundry, and the Claude apps gateway, so teams running Claude Code through their own cloud accounts get the same permission-prompt reduction as direct users. The release also adds a blocking onFailure setting for MCP tool hooks, letting hooks stop a tool call when they fail instead of letting it proceed.

**Source:** [Claude Code Docs - Changelog (v2.1.328)](https://code.claude.com/docs/en/changelog)

## 4. Pydantic AI 2.71.0 adds a harness capability set and rule-based permissions

The release adds harness capabilities (Goal, ToolBridge, WrapUpAtLimits, RequireVerification, PermissionRule), giving agent builders declarative building blocks for goal tracking, limits, verification, and tool permissions. It also adds ModelRouter and new provider options, and renames PeerNetwork to PeerConnection, which will break code that uses the old name.

**Source:** [GitHub - pydantic-ai v2.71.0 release](https://github.com/pydantic/pydantic-ai/releases/tag/v2.71.0)

## 5. Vercel AI SDK 7.0.177 adds an interrupt option for steering agents

The new interrupt option lets applications steer a running agent mid-run rather than waiting for it to finish. The package now also ships an AI SDK skill, so coding assistants working in a project can pick up the SDK's conventions directly from the installed package.

**Source:** [GitHub - vercel/ai releases (ai@7.0.177)](https://github.com/vercel/ai/releases)
